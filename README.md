# 虹の麓の郵便局

## サービス概要

「虹の麓の郵便局」は、大切なペットを亡くし、後悔や伝えられなかった思いを抱える飼い主が、ペットへ手紙を書くことで、本当の思い出を通して幸せだった記憶に立ち返るきっかけを届けるサービスです。

## このアイデアが生まれたきっかけ

作者自身が愛犬を突然亡くし、2か月間何も手につかなくなった経験が、このアプリの原点です。

友人と笑って話せるようになってからも、一人になると虚無感を感じ、不眠や拒食など生活に支障が出る状態が続きました。その経験から、ペットとの別れや後悔だけではなく、楽しかったことや大好きだったという幸せな感情にも、もう一度目を向けてほしいと考えました。

## 解決したい課題

ペットを失った飼い主は、お別れの場面や伝えられなかった思い、後悔ばかりを繰り返し考えてしまうことがあります。

このサービスが解決したい課題は、**後悔や悲しみに支配されている飼い主が、ペットとの幸せな記憶を思い出し、後悔ではなく感謝を胸に前を向くきっかけを提供すること**です。

## 想定ユーザー

ペットを失った悲しみと後悔でいっぱいになり、「自分が悪かったのではないか」と自分を責め続けている飼い主を想定しています。

特に、ペットを亡くして間もなく、散歩や食事の時間、帰宅時などに無意識にペットを探してしまい、そのたびに不在を実感している方です。

- 年齢：20代〜60代
- 一人暮らし、家族・同居人がいる方のどちらも対象
- 作者とユーザーの距離：過去の自分

## 提供したい価値

### 行動の変化

お別れの場面や後悔ばかりを思い出していた状態から、楽しかった記憶を意識的に思い出す時間を持てるようになることを目指します。

### 気持ちの変化

悲しみを消すのではなく、楽しかった過去を振り返ったときに、温かい気持ちを抱けるようになることを目指します。

### 考え方の変化

ペットは虹の橋の向こうで自分を見ているため、幸せそうにしている自分を見せたいと思えるようになることを目指します。

## 既存サービスとの違い

類似サービスとして「毎日あの子」があります。

本サービスでは、新しい創作エピソードで気持ちを埋めるのではなく、飼い主が実際にペットと過ごした記憶を尊重します。

- 手紙に新しいエピソードを追加しない
- 本当の思い出を「作り物のエピソード」で上書きしない
- 写真に近い画像ではなく、絵葉書のようなラフなイラストで温かみを表現する
- 料金を抑える

## MVPで実装する機能

MVPでは、「手紙を書いて送り、一定時間後に管理人からの返事を受け取り、保存された手紙と返事を読み返す」という一連の体験を成立させることを優先します。

### ユーザー機能

- ユーザー登録
- ログイン
- ログアウト
- ユーザーごとのデータ管理

### ペット情報

- ペットの名前を登録する
- 飼い主の呼び名を登録する
- MVPでは1ユーザーにつき1匹を登録する

### 手紙

- ペットへ送る手紙を書く
- 入力途中の手紙を一時保存する
- アプリを閉じた後も一時保存した内容を復元する
- 送信前に手紙の本文を確認する
- 手紙を保存する
- 手紙の送信時刻を保存する
- 手紙の保存時に、対応する管理人からの定型返信も保存する
- 送信後に一時保存した内容を削除する

### 配達演出

- 手紙の保存後、虹の麓へ届ける演出を表示する
- 複数の画像をスライドショー形式で表示する
- 演出後、返事を待つ案内を表示する

### 返事

- 返事の送り主は「管理人」で統一する
- MVPでは定型文の返事を使用する
- 定型返信は手紙の送信時に保存し、一定時間が経過するまで表示しない
- 開発・テスト環境では、手紙の送信から1分後に返事を受け取れる
- 本番環境では、手紙の送信から30分後に返事を受け取れる
- トップページで返事が届いたことを確認できる
- アプリを閉じている間のプッシュ通知はMVPでは実装しない

### 手紙一覧

- ボトムメニューには「手紙一覧」と表示する
- 「手紙一覧」の中を「送った手紙」と「届いた返事」に分ける
- 送った手紙と、管理人から届いた返事を一覧表示する
- 1通の手紙から対応する返事を確認できる
- 1通の返事から対応する手紙を確認できる
- 返事がまだ届いていない場合は、待機中であることを表示する

### ボトムメニュー

次の項目を表示します。

- ホーム
- 日記を書く
- 手紙一覧
- マイページ

「日記を書く」を選択した場合は、まだ利用できない機能であることを案内します。日記機能自体はMVP後に実装します。

MVPのマイページにはログアウトボタンだけを表示します。

## MVP後に実装する機能

- ペットの性別を登録する
- 性別に応じて返事の一人称（僕／私など）を出し分ける
- ペット名・飼い主の呼び名を使用前に確認・修正できるようにする
- ユーザーが書いた内容に応じたAI返信
- 日記の投稿
- ペットから日記を読んだことを伝える不定期の通知
- ペットの写真を登録し、手紙や返事に添える
- 複数のペットへの対応
- 絵葉書風イラストのバリエーション追加
- 手紙や通知を保存して振り返るアルバム機能
- 記念日に合わせた特別な手紙
- アプリを閉じている間にも届くプッシュ通知

## 大切にする設計方針

このアプリのユーザーは、ペットを失った悲しみや後悔を抱えています。そのため、通常のアプリでは軽微な不具合であっても、深く傷つける体験になる可能性があります。

特に避けたいのは次の問題です。

- 手紙の送信・受信でエラーが発生し、返事が届かない
- ペット名や飼い主の呼び名を誤って表示する
- 入力途中の手紙が失われる

優先するのは、サービスを使い続けてもらうことよりも、ユーザーの心を守ることです。

エラーが発生した場合は、技術的なエラーメッセージをそのまま表示せず、不安を煽らない言葉で状態を伝えます。
